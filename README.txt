WitchHand（女巫之手）简体中文汉化 1.1 — 补丁版
================================================

适用：Steam 版 WitchHand（appid 2420880），Windows
游戏版本：1.10c（主菜单右下角显示）
汉化版本：1.1（2026-10-23）
安装包大小：约 10MB（不含游戏本体）

1.1 更新：修复长卡名悬浮提示标题最后一个字换行、错位的问题
（如“炼金术士”“妖精城市”“水晶采石场”）。


一、这是什么
------------
本补丁只包含汉化差异，不含完整游戏文件：
- 字体与文本补丁（对原版 data.win 的差分，约 8.3MB）
- 12 个字体配置文件（.yy）
- 界面文本 game_strings.csv、卡牌文本 card_stats.csv
- 一键安装器与补丁工具

安装器会先校验你的原版 data.win 哈希，只支持上述版本。
版本不符时会拒绝安装，不会修改任何文件。需要你拥有正版游戏。


二、安装方法
------------
1. 完全退出游戏（包括 Steam 后台的 WitchHand 进程）。
2. 将压缩包完整解压到任意文件夹（不要只解压 install.bat）。
   请保留整个文件夹，不要删除其中的 backup 子目录。
3. 双击 install.bat。
   - 安装器会自动从 Steam 库中查找游戏目录；
   - 如果找不到，会提示你粘贴 WitchHand 文件夹路径。
   - 也可在命令提示符中运行：
     install.bat -GameDir "D:\你的路径\WitchHand"
4. 首次安装会把 16 个原文件备份到本目录
   backup\install_original，然后安装汉化。
5. 启动游戏即可。游戏语言保持默认 English，不需要切换。


三、卸载 / 还原
----------------
双击 uninstall.bat，会从 backup\install_original 还原全部 16 个原文件
（含 data.win、12 个 .yy、2 个 CSV、WitchHand.exe）。
请保留 backup 文件夹直到确认不再需要卸载。

如果备份丢失，或卸载时提示游戏版本未知：
在 Steam 中右键游戏 → 属性 → 已安装文件 → 验证游戏文件完整性，
即可恢复英文原版。


四、注意事项
------------
1. Steam 的“验证游戏文件的完整性”或游戏更新会覆盖汉化。
   如被还原，重新运行 install.bat 即可。
2. 游戏更新后，data.win 哈希会变化，本补丁会拒绝安装。
   请等待对应版本的汉化补丁。
3. 汉化不修改存档。存档位置：
   C:\Users\<用户名>\AppData\Local\WitchHand
4. Steam 云同步只同步存档，不会同步汉化文件。
5. 只支持简体中文。
6. data.win 与 12 个 .yy 字体文件必须成对安装（安装器已处理）。
   游戏运行时从 .yy 读取字形布局，只替换其中一部分会导致字符错位。
7. 安装器需要调用本目录 tools\zstd.exe 应用补丁。若杀毒软件拦截，
   请将本目录加入信任后重试。


五、汉化内容
------------
1. 界面文本 293 条：标题菜单、设置、教程提示、卡牌提示、结局文本等。
2. 卡牌文本 483 张：卡名、说明、风味文本。
3. 游戏内 12 种字体补充中文字形（最多 1538 个字符，含标点与一个
   不可见占位符），保留原有英文字形、字距与排版风格。
4. 直接写死在程序里的 4 句操作提示也已汉化。
5. 语言栏 English 一列显示为中文；德语、波兰语、法语内容未改动。

已知保留英文的部分（为避免破坏按键设置，故意不翻译）：
- 按键名称：LMB / MMB / RMB / Space / Tab / Backspace / On
- 提示框标题：Sell / Explore / Spells
- 开发者名字：Jon
